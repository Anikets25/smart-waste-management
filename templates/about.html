ℹ️ About This Project

Smart Waste Management System — B.Tech Final Year Project

🎯 Project Goal

The Smart Waste Management System is a web-based platform that lets citizens report waste and garbage problems in their local area. The goal is to create a simple, transparent link between the public and waste management administrators, so reported problems are tracked and resolved — not forgotten.

⚙️ How It Works

1
Citizen Reports a Problem

Fill in a form with a description, waste category, location, and optional photo. Receive a unique complaint ID.

2
Admin Reviews the Complaint

An administrator logs into the secure admin panel, views all submitted complaints, and updates their status.

3
Citizen Tracks the Status

Using the complaint ID, the citizen can check the current status at any time: Submitted → Under Review → In Progress → Resolved.
